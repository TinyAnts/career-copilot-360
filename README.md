# Career Co-Pilot 360

Landing page for Career Co-Pilot 360: Medicine & Engineering admissions guidance in Europe by Nagarajan S. (Raj).

Vite + React + Tailwind CSS v4. Fully static.

## Develop
```bash
npm install
npm run dev
npm run build   # -> dist/
```

## Deploy
Cloudflare Pages, auto-deploys from `main`. Build: `npm run build`, output: `dist`.

## Content
Everything lives in `src/pages/Home.tsx` (BOOKING_FORM, CONTACT_EMAIL, pathways, universities, sections). Assets in `src/assets/` (webp images + compressed mp4 videos).
